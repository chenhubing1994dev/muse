# Muse 网站 · 上线步骤（约 10 分钟，免费）

这个文件夹就是完整网站，不需要服务器、不需要写代码。

## 第 0 步：填你的链接（可选，随时可改）
用记事本打开 `index.html`，搜索 `SITE_CONFIG`，把小红书 / 抖音 / B站主页链接和店铺链接填进双引号里。
留空的会自动隐藏，所以现在不填也能先上线。

## 方案 A：Cloudflare Pages（推荐，免费、带 HTTPS）
1. 注册 / 登录 dash.cloudflare.com
2. 左侧 Workers 和 Pages → 创建 → Pages → 上传资产（直接上传）
3. 项目名填 `muse-ai-check`（会得到 `muse-ai-check.pages.dev`）
4. 把本文件夹（或 `muse-site-20261124.zip`）拖进去 → 部署
5. 以后改了内容，在该项目里“创建新部署”再拖一次即可

## 方案 B：Netlify Drop（最快，无需配置）
打开 app.netlify.com/drop，把整个文件夹拖进去，几秒得到一个网址。注册账号后可保留和改名。

## 方案 C：GitHub Pages
新建公开仓库 → 上传本文件夹所有文件 → Settings → Pages → Branch 选 main → Save。

## 注意
- 平台界面会改版，按钮名称可能略有不同。
- 以上都是海外托管，国内能访问但速度一般；主要流量建议放在小红书 / 抖音主页，网站作为“资料下载 + 店铺入口”。
- 若要用自己的域名并放在国内服务器，需要先办 ICP 备案。
- 上线后把网址放进各平台主页简介（注意部分平台限制外链，可写“主页见简介/私信领取”）。
