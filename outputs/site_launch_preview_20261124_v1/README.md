# Muse Static Site Preview

- Pages: home/showcase, products, portfolio sample.
- Local static assets only; no backend, analytics, payment processing or customer submission endpoint.
- Inquiry form only prepares a local text draft and copies it when browser permission allows.
- robots.txt disallows crawling; all pages remain a preview and must not be treated as a public launch.
- Before deployment: approve the sample's font/commercial rights, review legal/privacy copy, configure an owner-controlled contact channel, confirm domain/HTTPS, and deliberately remove the crawl block only after approval.
- Payments are not enabled; no price is represented as a live offer.
