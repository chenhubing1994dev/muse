# 第 8 集｜截图不是证据：如何核对一张“新闻截图”

**小红书标题**：新闻截图别急着转，先查这3步
**抖音/视频号标题**：一张新闻截图是真是假？转发前 2 分钟核对

**正文**：
群里刷到一张“新闻截图”，看着很像真的。但截图很容易被裁剪、拼接或改字，拿去问 AI，它也可能顺着截图内容往下讲。
转发前的 3 步核对：
1⃣ 找原文：用标题或关键句加引号搜索，找到媒体官网或官方账号的原始报道
2⃣ 看时间：确认发布日期，警惕旧闻被重新截图当新消息
3⃣ 比细节：标题、数字、人名、引语逐字对照，也看看被裁掉的上下文
找不到原文，就先不转发，可以说一句“暂未查证”。
