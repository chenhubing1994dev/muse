# AI 三步查证清单

适用：检查 AI 回答中的事实性主张、数字、日期、引用及因果结论。

## 第一步：拆主张

- [ ] 把长答案拆成独立、可核验的短主张。
- [ ] 圈出人名、机构、日期、数字、比例、地点、法规、研究结论及引文。
- [ ] 区分事实、推断、意见、预测和创作内容。
- [ ] 把含糊词语改写成可检验问题（例如「很多」「大幅」「最新」）。
- [ ] 记录 AI 原文，不要先替它修饰或补全。

## 第二步：查原始来源

- [ ] 找到原始文件、官方公告、研究论文、数据集或一手记录。
- [ ] 确认发布机构、作者、发布日期、版本和适用范围。
- [ ] 打开原文，核对主张对应的章节、页码、表格或数据行。
- [ ] 确认引用是否真的支持该主张，而不只是主题相似。
- [ ] 记录原文摘录和可复查定位。
- [ ] 若来源打不开、已撤回、版本不明或只有二手转述，明确标记。

## 第三步：主动找反证

- [ ] 搜索与原结论相反的证据。
- [ ] 寻找不同研究、不同数据集或不同时间段的结果。
- [ ] 检查样本、地区、时间、定义和统计口径是否一致。
- [ ] 检查是否存在遗漏条件、混淆相关与因果、选择性引用。
- [ ] 记录尚未解决的矛盾与替代解释。

## 最终状态（只能选一项）

- `verified_with_scope`：证据支持，但必须保留适用范围。
- `partially_supported`：只有部分内容得到支持。
- `contradicted`：可靠证据与主张冲突。
- `unverified`：目前没有足够证据。
- `unknown`：关键来源、数据或上下文缺失。

## 发布前最后检查

- [ ] 每个重要事实都有可追溯来源。
- [ ] 没有把 AI 自己生成的引用当成已验证来源。
- [ ] 已记录反面证据和不确定性。
- [ ] 没有把推测包装成事实。
- [ ] 人工复核者已确认原始来源。
