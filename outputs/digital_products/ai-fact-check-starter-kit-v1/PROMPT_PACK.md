# AI 查证提示词包

使用提示：提示词只能帮助整理研究工作，不能代替打开原始来源及人工复核。若模型无法访问来源，应明确说明，不得假装已经阅读。

## A. 拆分原子主张

```text
请把以下回答拆分成独立、可核验的原子主张。
分类标注：事实、推断、意见、预测或创作内容。
优先标出人名、机构、日期、数字、比例、引用和因果结论。
不要补充原文没有的事实。对含糊词语列出需要澄清的问题。
每条主张请保留原句片段，并标记需要什么类型的一手来源。

回答：
[贴上 AI 回答]
```

## B. 检查来源是否真的支持主张

```text
请逐条检查以下主张与我提供的来源摘录是否一致。
只根据提供的原文判断，不要凭记忆补充。
分别指出：直接支持、部分支持、反驳、无关或无法判断。
给出具体原文定位；若没有定位，请标记 unknown。
不要把主题相似当作证据支持。

主张：
[贴上单条主张]

来源名称、版本及定位：
[填写]

原文摘录：
[贴上原文]
```

## C. 主动寻找反证

```text
请为以下主张设计一份反证检索计划。
列出可能推翻、限制或缩窄该主张的资料类型、检索关键词、不同解释和关键混淆因素。
优先寻找原始数据、独立研究、官方修订及不同时间段的资料。
如果没有实际检索能力，请只提供检索计划，不要声称已经找到证据。

主张：
[贴上单条主张]
```

## D. 评估来源质量

```text
请评估以下来源的证据质量，而不是直接判断主张为真。
检查作者与机构、原始性、发布日期、版本、方法、样本、利益冲突、可复核性和适用范围。
指出来源能支持什么、不能支持什么，以及仍需哪些独立来源。
不要因为来源是官方或学术出版物就自动给出最高可信度。

来源：
[贴上来源信息及摘录]
```

## E. 输出谨慎结论

```text
请根据我提供的支持证据、反面证据和未解决问题，生成一份可审计的结论。
每项结论必须对应证据定位。
明确区分事实、推断和意见。
若证据不足，请使用 unknown 或 unverified，不要猜测补齐。
保留矛盾、适用范围及局限，不要强行给出确定答案。

研究记录：
[贴上证据账本]
```
