# 反证与替代解释工作表

目的：避免只搜集支持原结论的资料。反证不是为了证明 AI 一定错，而是检验原结论是否站得住脚。

## 1. 原始主张

- Claim ID：
- 原始主张：
- 当前支持证据：
- 当前结论及适用范围：

## 2. 主动寻找反面资料

尝试以下检索方向：

- 原始研究是否有勘误、撤回或后续修订？
- 是否存在不同地区、不同样本或不同时间段的相反结果？
- 是否有官方数据与新闻转述不一致？
- 是否有原始文件中的限制条件被二手资料省略？
- 是否有独立研究无法复现该结果？

## 3. 替代解释

- 还有什么原因可以解释同一现象？
- 相关性是否被误读成因果关系？
- 统计口径、分母、样本或时间窗口是否不同？
- 是否存在选择偏差或幸存者偏差？

## 4. 反证记录

| 来源 | 定位 | 关键摘录 | 对原主张的影响 | 证据质量 |
|---|---|---|---|---|
|  |  |  | 支持 / 反驳 / 限定 | 高 / 中 / 低 |

## 5. 暂定结论

- [ ] 原主张在明确范围内仍获支持。
- [ ] 原主张需要缩窄或补充条件。
- [ ] 证据互相冲突，暂不能下结论。
- [ ] 原主张受到可靠证据反驳。
- [ ] 资料不足，保持 unknown / unverified。

不要为了得到一个漂亮答案而消除矛盾；保留矛盾本身就是研究成果。
