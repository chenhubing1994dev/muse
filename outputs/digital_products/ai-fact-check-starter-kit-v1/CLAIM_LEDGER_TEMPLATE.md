# 主张与证据记录表

每一行只记录一个可独立核验的主张。不要把整段 AI 回答塞进同一行。

| 字段 | 填写内容 |
|---|---|
| Claim ID | 唯一编号 |
| AI 原文 | 完整复制相关句子 |
| 原子主张 | 改写为一个可验证句子 |
| 主张类型 | 日期 / 数字 / 人物 / 引用 / 因果 / 其他 |
| 来源名称 | 原始出版物或机构 |
| 来源 URL | 可直接打开的链接 |
| 作者 / 发布者 | 原始作者或机构 |
| 发布日期 / 版本 | 日期及版本号 |
| 定位 | 页码、章节、表格、段落或数据行 |
| 原文摘录 | 足以支持或反驳主张的短摘录 |
| 证据方向 | 支持 / 反驳 / 无关 / 不确定 |
| 证据质量 | 高 / 中 / 低，并解释原因 |
| 反面证据 | 反例、不同研究或相反数据 |
| 未解决问题 | 缺失数据、定义或适用范围 |
| 当前状态 | verified_with_scope / partially_supported / contradicted / unverified / unknown |
| 下一步 | 需要打开什么来源或向谁确认 |
| 复核者 / 日期 | 人工复核记录 |
