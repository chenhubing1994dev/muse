# Research-to-Script Sprint｜服务产品页草案

> 状态：内部销售验证稿；未公开上线、未接受订单、未收款。所有价格与交付时限均为待验证假设。

## 一句话价值

把一个值得讨论的主题，变成一份有来源、有反证、有边界的研究简报，以及一条可以进入制作流程的原创短视频脚本。

## 适合谁

- AI、科技、教育、商业与知识类内容创作者
- 需要把复杂资料转成短视频或社交内容的小团队
- 不想把 AI 生成的说法未经核验就发布的人

不适合：要求保证结论、伪造引用、代写学术作业、提供医疗/法律/投资个案意见，或要求未经授权复制第三方作品的客户。

## 首轮试点交付

**单主题 Research-to-Script Sprint**

1. 主题与受众简报：一个明确问题、目标观众与内容目的
2. 证据矩阵：最多 5 个来源，记录出处、支持内容、反面证据、限制与未知
3. 主张核验：把核心说法拆成可检查的主张，标记 supports / partially supports / contradicts / not found / unclear
4. 原创内容：一条约 45–60 秒短视频脚本、3 个开场 Hook、一个标题与简介、标签和置顶评论
5. 发布前清单：版权/许可、AI 内容披露、字幕、画面安全区、事实复核与人工审批事项

**不包含：** 保证流量或销售、代运营账号、公开发布、付费广告、法律意见、学术认证、无限次修改、未经授权的素材或声音克隆。

- 不在验证前购买广告或新增付费 API

## 建议流程

1. 客户提交主题、受众、语言、平台与期望交付日期
2. 先做范围确认：资料是否可获取、是否涉及高风险专业判断、是否有权使用客户提供的素材
3. 发出明确报价、交付范围、修改次数、取消/退款条款
4. 只有在双方确认并通过安全支付流程后才开始计费工作
5. 交付草稿供客户审阅；客户批准后才由客户自行发布或另行授权
6. 记录实际工时、修改、退款、平台费用与净收入

## 订单前必需信息

- 联系方式（仅在确有必要时收集）
- 主题与需要核验的具体主张
- 目标受众、语言、平台与内容形式
- 截止日期及资料来源
- 客户是否拥有所提交素材的使用权
- 是否需要仅研究简报，或研究简报 + 脚本

不要在普通表单收集身份证件、密码、支付卡资料、医疗记录或其他不必要敏感信息。

## 质量与诚信标准

- 每个关键事实都应回链到原始来源；来源不存在、无法访问或无法确认时明确标注
- 不把相关性写成因果，不把单一研究外推成普遍规律
- 必须主动寻找反证、替代解释与适用限制
- AI 生成内容须按平台要求披露；未经许可不复制论文图表、图片、音乐、字体或第三方视频
- 高风险主张必须人工复核；证据不足时保留“未知”，不为迎合客户改写事实

## 发布前必须补齐

- [ ] 至少 5 位目标客户访谈，记录问题与真实异议
- [ ] 完成服务条款、隐私说明、取消/退款规则与发票/税务流程核查
- [ ] 建立安全支付和订单对账流程；不在聊天中收集支付凭证或卡号
- [ ] 建立交付模板、版本记录、事实核验记录与客户验收标准
- [ ] 完成一轮模拟订单计时，计算人工时间、算力/平台成本与净贡献
- [ ] 用户审核最终对外文案与价格后，才可公开销售

## 成功指标

不是“发了页面”或“有人点击”，而是：合格咨询 → 明确报价 → 真实付款 → 按范围交付 → 客户验收 → 退款/费用扣除后的正净收入。未发生的指标记为 unknown 或 0，不用推测填补。
