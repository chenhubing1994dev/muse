# Quote Intelligence launch preview

- Purpose: isolated, local-only product landing-page draft for internal review.
- Product status: prototype/demo; no customer data or real supplier quotes.
- Sample: links to `../quote_intelligence-demo.md`, generated from synthetic SGD/USD examples.
- Price: US$9 is an unvalidated hypothesis only.
- No checkout, payment provider, tracking, analytics, lead form, or public deployment.
- Current feature boundary: normalized JSON input; PDF/XLSX/OCR ingestion and supplier verification are not implemented.
- Human decision boundary: the tool reports comparable amounts and uncertainties; it does not select a supplier.
- This preview is deliberately stored in a new isolated directory and does not overwrite the existing site owner's files.
