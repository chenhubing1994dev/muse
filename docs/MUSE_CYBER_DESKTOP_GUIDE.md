# MUSE · 赛博玄枢桌面客户端使用说明书

> 版本：v0.2（Neo-Cyber Celestial · 赛博玄枢星舰中枢）  
> 适用客户端：`desktop\src-tauri\target\release\muse-desktop.exe`  
> 桌面快捷方式：`桌面\Muse.lnk` 与 `桌面\Muse-Desktop.lnk`

---

## 一、如何启动与快捷方式说明

1. **双击桌面图标直接启动（零黑框秒开）**
   - 桌面上已创建 `Muse.lnk` 与 `Muse-Desktop.lnk`，直接指向独立编译好的原生客户端 `D:\AI AGENT\Muse\desktop\src-tauri\target\release\muse-desktop.exe`（工作目录为 `D:\AI AGENT\Muse`）。
   - 启动后，Rust 桌面壳会自动在后台拉起受 Bearer 会话保护的回环 Python 状态引擎（优先使用 `.venv\Scripts\python.exe`），关闭客户端窗口时自动回收该后台进程。
2. **如需重新编译客户端**
   - 在项目根目录运行：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Muse-Desktop.ps1 -Rebuild`
3. **如同时需要浏览器 / 局域网手机配对版**
   - 可继续使用 `scripts\Muse-Start.ps1` 启动带 8 位配对码的局域网浏览器控制台（端口 `8766`），日常关闭用 `scripts\Muse-Stop.ps1`。

## 二、现在能实现的功能 vs 将要完成的长期愿景

| 分类 | 模块 | 当前真实能力与入口 | 边界说明 |
|---|---|---|---|
| **已实现** | 赛博星环浑天仪 (`#overview`) | 三重星环交互（二十八星宿、八卦阵盘、普罗米修斯五阶）、真实干支参考、CPU/RAM 并发护栏 | 未知 GPU 显存严格标 `UNKNOWN`，绝不从 CPU/RAM 推算 |
| **已实现** | 八卦与星宿假设工坊 (`#celestial-lab`) | 种子三钱模拟起卦、上下八卦合卦、手动六爻（本/之/互/错/综）、四体系研究提问、一键存为本地灵感候选 | 明确标记 `symbolic_hypothesis_only` 与 `is_evidence=false`，绝不写回个人记忆或批准任务 |
| **已实现** | Research Wiki 知识星图 (`#knowledge-starmap`) | 拖拽/缩放 Canvas 宇宙拓扑、按类型与关键词检索、点击星体查看详情/来源/邻居连续跃迁、治理审计计数 | 候选证据未人工审核前不会自动晋升为已验证事实 |
| **已实现** | 自主运行时 & 一键流水线 (`#daemon-runtime`) | 按需启动/暂停/恢复/单轮执行监督循环、提交可复现短片配方并实时追踪进度 | 不会私自注册开机自启或 Windows 系统服务 |

| **部分实现** | 视频创作与成果库 (`#products`) | 本地 FFmpeg/Remotion 素材剪辑、ComfyUI Wan 2.1 文生视频、预览/下载 MP4 与 ZIP、创作时间线、粤语字幕逐条人工审校 | Wan 2.1 生成依赖本机 ComfyUI 就绪；成片默认 `testing`，需人工审片 |

## 三、分步操作教学

### 1. 顶部驾驶舱控制
- **核心状态灯**：顶部右侧显示 `LIVE · 本地核心 · 在线` 代表 Tauri 已安全连上本机 Python API。
- **全息超频 / 静态护眼**：一键开关全息旋转动效与扫描线（也自动尊重系统「减少动态效果」设置）。
- **星舰舱段聚焦栏**：默认「◈ 全景星舰」展示全部模块；也可一键聚焦到「星环与八卦星宿」「Research Wiki 星图」「Agent 星系与队列」「普罗米修斯与愿景」「创作与影像工坊」。
- **Ctrl + K 快速跳转 / 底部快捷指令坞**：随时唤出全局指令搜索，或点击屏幕底部悬浮指令坞直达任意核心模块。

### 2. 操控三重赛博星环（`#overview`）
1. **外环（二十八星宿）**：按东方苍龙（青）、北方玄武（冰蓝）、西方白虎（银）、南方朱雀（金）排列。点击任意星宿点，右侧检视舱会显示星官主题与设计追问。
2. **中环（先天八卦）**：用霓虹阴阳爻绘制乾、兑、离、震、巽、坎、艮、坤。点击任意卦象查看系统隐喻，还可点击 **「以此卦为下卦推演六十四卦 ↗」** 直接跳转到八卦工坊。
3. **内环与核心（普罗米修斯五阶）**：点击「点火 / 求知 / 融合 / 创造 / 传承」查看各阶段真实本地数据库累计成果。

### 3. 使用八卦与星宿假设工坊（`#celestial-lab`）
1. 在顶部「探索问题 / 创意目标」输入你想研究或创造的命题（例如：「如何设计资源感知的多智能体研究流水线？」）。
2. 选择 **种子三钱模拟**（输入可见种子词）、**上下八卦合卦**（点选上下卦）或 **手动六爻输入**（6/7/8/9）。
3. 点击 **「运行确定性八卦推演」**：界面会绘制自下而上的六爻阴阳动变图，给出本卦、之卦（变卦）、互卦、错卦、综卦，以及 **「易经 · 奇门 · 紫微 · 大六壬」四体系对照矩阵与可证伪研究假设**。
4. 如果某条假设很有启发，点击 **「存入本地灵感候选（待研究）」**，即可安全保存到本地灵感池，后续在研究模块验证。

### 4. 漫游 Research Wiki 知识星图（`#knowledge-starmap`）
1. **视图操控**：在星图画布上按住左键拖拽平移；滚轮或右上角 `放大 + / 缩小 - / 重置视口` 缩放视角。
2. **按类型与关键词过滤**：点击上方类型按钮（`主张 Claim` / `灵感 Idea` / `来源 Source` / `实验 Exp` / `决策 Decision` / `失败 Failure`）或输入关键词点 **「检索星群」**。
3. **星体档案与邻域跃迁**：点击画布上任意星体，右侧立即展示完整摘要、来源 `Provenance`、证据候选计数和直接相连的邻居节点；点击任意邻居按钮可连续跃迁追踪知识脉络。
4. **治理欠账仪**：画布下方实时显示孤立节点、无证据 Claim 与待审查证据候选，方便按计划开展数据治理。

### 5. 审阅 AI Agent 星系与统帅路由预演（`#agents`）
1. 中心节点为唯一调度权威 **Muse Commander**（竞态调度器恒为 `0`）；内环为 8 大专家角色行星，中环为实连在线 Agent 卫星，外环为本机能力节点。
2. 点击内环任意专家行星，可查看其角色信任等级（`trust_tier`）与真实历史 `agent_runs` 成功次数。
3. 在右侧 **「统帅路由沙盒预演」** 输入任务描述（例如：「研究并开发系统架构与安全审查测试」）点击 **「路由预演」**，星系图上会用金色高亮点亮匹配到的专家行星，并展示得分与命中关键词（只读仿真，不会自动派工）。

### 6. 价值创作台、灵感工坊与视频审片（`#value-studio`, `#inspirations`, `#products`）
1. **价值创作台**：填写创作题目、目标受众与观看收获，点 **「评估选题价值」** 获取六维评分与建议路径，随后点 **「存入灵感池」** 或 **「生成视频」** 一键带入视频创作表单。
2. **灵感工坊**：默认只保存本地；只有当你主动勾选 **「允许 Muse 使用这段灵感进行联网研究」** 后，自主研究才会使用该条目检索公开资料。
3. **视频创作与人工审片**：支持 FFmpeg 本地素材剪辑（素材放 `data/video_sources/<文件夹名>`）与本机 ComfyUI Wan 2.1 文生视频。成品进入「成果产品库」后，可预览、下载 MP4 / ZIP、查看时间线、提交粤语字幕逐条审校或审片意见回流。

## 四、常见问题与安全提示

- **为什么有的专家显示「模板元数据 · 待接入执行器」？**  
  Muse 严格遵守不造假原则：只有真正注册并保持心跳的本地 HTTP / Ruflo Agent 才会显示为实连在线；未接入的内置专家会诚实标注为模板。
- **为什么 GPU 显存显示 `UNKNOWN`？**  
  根据产品宪章，在显存探测未独立验证之前，系统严禁通过 CPU/RAM 猜测显存，以防止并发任务过载。
- **想完全停止所有后台任务怎么办？**  
  直接关闭桌面客户端窗口会自动回收桌面专属 Python API；如果你另外通过 `Muse-Start.ps1` 启动过常驻守护进程，可在项目目录运行 `powershell -File scripts\Muse-Stop.ps1`。
