# 操作指南：单位经济模拟器与报价单识别

## 单位经济模拟器（`src/muse/unit_economics.py`）
**它做什么**：给一个产品点子算账：每卖一份净赚多少、做出来要先花多少、卖多少份才回本。所有结果都标着 `simulation_not_forecast`（模拟，不是预测），价格标着 `price_hypothesis`（价格假设），**不会**计入收入账本。

**强制规则**
- 打分前必须写清四条反证：已有的免费替代品、用户换用的阻力、获客难度、合规风险。少一条就拒绝计算。
- 实验开始前必须先写好“止损线”，例如“第 14 天已结算订单少于 3 单就停”。到期没测量也算触发止损。浏览量不能当作止损或成功指标。
- 金额只接受整数或小数字符串，不接受浮点数，避免舍入误差。

## 报价单识别（`src/muse/quote_ingest.py`）
**它做什么**：把供应商发来的 CSV、Excel（.xlsx）、文字版 PDF 报价单里的品名、数量、单位、单价读出来，交给已有的报价对比（`quote_intelligence`）。每一行都记着出处（例如 `Sheet1!A4`、`row 3`、`text line 7`）。
- 支持中文表头（品名 / 数量 / 单位 / 单价）和带 ¥、$、千分位的金额。
- 供应商名称、币种、是否含税、总价是否完整，由你确认后填写，程序不猜。
- PDF 识别可信度永远标为 `low`，每一行都需要你核对；扫描版 PDF 会提示“需要 OCR”。
- 压缩炸弹、超大文件、非报价格式一律拒绝。

**诚实边界**：两个模块都已在沙箱测试中通过（9/9），但还没有接到界面按钮或 Value Radar 例程上。这一步留在后续批次。
