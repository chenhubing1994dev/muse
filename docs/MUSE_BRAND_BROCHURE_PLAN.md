# MUSE 品牌图文宣传册制作计划

- 计划日期：2026-11-17
- 状态：in_progress（第一版 5 页 A4 PDF 与独立封面已生成并核对元数据；项目内 share/ 目录目前为空；逐页视觉复核待完成。第二版产品介绍册进入内容规划）
- 对应产品：Muse / Hi Muse AI
## 一、交付物

1. **高清 PDF 宣传册**：A4 版式，适合屏幕阅读、转发与打印；建议 5–8 页，最终页数由内容密度和排版质量决定。
2. **独立高清封面图**：可单独用于社交平台、演示文稿和宣传页面。
3. **可编辑宣传文案源稿**：保留标题、正文、图注、产品能力说明与版本信息，便于后续迭代和多渠道改写。
4. **可选分享版图片**：PDF 定稿后导出适合手机阅读/社交转发的长图或分页 PNG/JPG。

## 二、内容结构

- 品牌定位与愿景：Muse 是以统一 Commander 为调度中心，连接灵感记忆、研究学习、工具/Agent 协作、创作交付和验证改进的本地优先智能体平台。
- 核心架构：灵感与感知、长期记忆、研究求证、任务规划、专家协作、创作生产、质量验证、经验回写。
- 能力展示：只展示有代码、运行记录或可复现实测支持的现有能力；标明验证范围、限制和日期。
- 视频创作生产线：选题 → 研究 → 脚本/分镜 → 素材与旁白 → 视频生成 → 剪辑包装 → 质量检查 → 交付 → 发布后数据复盘。
- 未来路线图：清楚区分已实现、正在开发、待验证和长期愿景，不把计划包装成现成功能。
- 合作与行动入口：仅使用真实可用的项目主页、演示方式或联系渠道；不得虚构网址、客户、合作、收入或用户数据。

## 三、视觉与版式方向

- 主视觉：深空宇宙、金色神经核心、星环与能量轨道。
- 东方意象：神龙、凤凰、仙山/宫阙等作为品牌叙事元素，与未来科技界面融合。
- 色彩：深蓝/黑为底，金色为主强调色，青蓝为辅助科技光效；确保正文对比度与打印可读性。
- 风格：史诗感、未来感、东方神话气质；避免廉价模板感、过度堆砌特效和难以阅读的文字。
- 字体：使用许可清晰、支持简繁中文的字体；嵌入 PDF 或记录字体来源与授权条件。

## 四、事实与宣传边界

- “宇宙最强”“意识体”等只能作为品牌愿景或修辞表达，不得表述为客观排名，也不得宣称软件已被证明拥有主观意识或人类式体验。
- 每项能力按 **已验证 / 已实现但未完成端到端验收 / 开发中 / 规划中** 标注。
- 性能、测试数量、硬件适配、视频样片、语音能力和商业结果，必须能追溯到具体测试记录、成品文件或正式数据。
- 未完成的粤语旁白、自动发布、收益闭环、无人值守运行等，不得宣传为已全面可用。
- 不展示密钥、私人记忆、隐私、未授权本机路径或敏感运行信息。
- 不使用未经许可的第三方图片、字体、音乐、商标或项目素材；记录 AI 生成图的来源及必要披露信息。

## 五、执行步骤

1. 汇总最新产品愿景、架构、能力 Backlog、进度文档和可展示的真实成果。
2. 建立“能力事实表”：每项主张对应证据、状态、日期、限制与可公开程度。
3. 完成宣传文案初稿与信息层级；先审事实，再做视觉排版。
4. 制作封面主视觉及内页图表/流程图，统一品牌视觉规范。
5. 排版生成 PDF，并导出封面与分享版图片。
6. 检查中文字体、断行、页码、链接、图片清晰度、PDF 可搜索性、文件大小和打印边距。
7. 对照能力事实表逐项复核，修正所有夸大或无法证明的表述。
8. 交付文件、记录 SHA-256、文件大小、页数、输出路径和版本日期；保留可编辑源稿。

## 六、验收标准

- PDF 可正常打开，页数与页面尺寸正确，中文无乱码、缺字或字体替换问题。
- 封面与内页图像清晰，无拉伸、裁切错误或水印残留。
- 标题层级、正文可读性、页码、目录/导航（如适用）和版面风格一致。
- 所有产品能力主张均能追溯到项目记录；现状与路线图明确分离。
- PDF、封面图、源稿均存在于约定项目输出目录，并可通过项目文件交付流程下载。
- 完成内容审查与文件完整性校验后，状态才可从 planned 更新为 completed。
