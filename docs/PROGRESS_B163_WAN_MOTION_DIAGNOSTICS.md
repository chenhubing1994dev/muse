# B163｜Wan 2.1 低运动诊断补充

日期：2026-11-19

## 目标

对 B160 的 384×384、17 帧、8 FPS、2.125 秒 Wan 2.1 T2V staging 输出增加独立光流诊断，区分“帧完全重复”与“帧有变化但运动幅度不足”。本轮只读分析既有文件，不重新运行 GPU 推理，不修改任何生产视频。

## 输入与方法

- 输入：`D:\AI\ComfyUI-Rinsei\portable\ComfyUI_windows_portable\ComfyUI\output\muse_b160\wan21_t2v_motion_test_00001_.mp4`
- OpenCV 读取 17 帧并转灰度；对 16 对相邻帧使用 Farneback dense optical flow（pyr_scale=0.5、levels=3、winsize=15、iterations=3、poly_n=5、poly_sigma=1.2）。
- 每对记录平均光流幅度、95 分位光流幅度、光流幅度大于 0.5 px 的像素比例，以及平均绝对亮度差。

## 结果

- 17 帧成功读取，16 对相邻帧均完成计算。
- 相邻帧平均光流幅度中位数：**0.2767 px/frame**；最大值：**0.4137 px/frame**。
- `flow magnitude > 0.5 px` 的像素比例约 **10.77%–19.51%**。
- 平均绝对亮度差约 **0.4422–1.2950**（8-bit 灰度级）。
- 与 B160 的 17/17 unique framemd5 结果一致：并非完全重复帧，但绝大多数像素的位移很小，支持“低运动/需人工复核”的判断。

## 判定与边界

- 本结果是诊断证据，不是经人工标注校准的通用运动质量阈值；不能单独用于自动判定镜头合格。
- 继续保留 B160 的结论：该镜头未通过生产运动 QA，不进入生产素材，不替换 B149 镜头，不降低现有 QA 门槛。
- 本轮 ComfyUI 队列为空，但 Runner 观察到另外 2 个运行任务，且显存剩余约 2.6 GiB。因此本轮没有启动新 GPU 推理，避免与现有任务争抢资源。
- 后续应在资源空闲时进行受控 prompt/seed/steps 对照实验，并将光流指标与人工标注的主体运动、镜头运动分开比较；只有完成运动、音频、字幕、解码及交付包 QA 才能进入发布候选。
