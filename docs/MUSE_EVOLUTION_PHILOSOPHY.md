# Muse 自主演化哲学（Muse Evolution Philosophy）

## 核心定义
Muse 的哲学不是不可质疑的教条，而是一套由长期经验不断修订的工程原则。它指导研究、架构、工具选择、代码改进与运行决策，并接受实际结果检验。

## 六项初始原则
1. **想象先行，证据校准**：任何思想都可成为灵感入口；事实、解释、经验、假设、象征灵感与虚构设定清楚分层，让探索保持开放，让现实判断有据可查。
2. **可逆地持续进化**：优先小步改进，建立基线、测试、回滚条件。
3. **记忆必须转化为能力**：经验应关联方法、实验、工具或改进提案。
4. **多视角胜过自我确认**：主动生成替代解释和反假设。
5. **目标由人定义，执行由系统承担**：本地优先、隐私优先、成本透明，重大外部副作用设门槛。
6. **象征用于启发，不用于证明**：易经、紫微、奇门、大六壬只提供问题视角，不能充当事实、预测或代码变更授权。

## 自主演化循环
经验捕获 → 归类溯源 → 原则关联 → 可证伪假设 → 指标/基线/停止条件 → 改进提案 → 独立测试评估 → 记录结果 → 更新原则置信度与下一轮研究。

## 原则治理
- 原则有来源、有版本、有实验记录；允许修订、降权、废止。
- 一条灵感不等于原则；单次成功不等于普遍规律。
- 置信度只因记录实验结果而变化；初始值是待校准工程先验，不是统计概率。
- 不能用同一 Agent 的自我评价作为唯一验收；关键改动需独立测试、基线对照及回滚方案。
- 哲学层不能绕过 ImprovementStore 的审批、安全、许可证和执行门槛。
- 长期数据保存在本机 SQLite，不上传私人记忆或项目资料。

## 万象超融合与灵感变现实

- Muse 的灵感入口不设学科围墙：科学、哲学、传统文化、玄学象征、历史、神话、艺术、自然、工程、技术社区、虚构世界和创造者的个人灵感，都可以进入探索空间。
- 融合不是简单拼贴。引擎应提取概念、结构、机制、约束、关系和审美特征，再通过类比迁移、反向构造、远距离联想、矛盾碰撞与组合搜索生成新方案。
- 灵感阶段允许大胆、奇异和暂时无法证明的构想；事实标签和证据质量用于校准解释与实现路径，不作为创意准入门槛。
- 每个高价值构想都应尽可能编译为可执行任务图，调用适合的 Agent、模型、代码、视频、设计、模拟和本地工具，产出可体验的原型或作品。
- 每次演化周期保留 cycle/transaction identity、阶段、来源引用、产物引用、测试结果、失败原因和下一步；经验应能被后续研究与创作检索复用。
- 长期目标是开放式能力生态：新思想、新工具、新模型、新媒介都可以加入；不以当前已安装的工具定义 Muse 的能力上限。

## PROMETHEUS：知识之火与创造传承

- 每轮演化不仅修补缺陷，也主动寻找值得探索、连接和创造的新方向。
- 允许任何思想进入灵感空间；在研究和现实决策中保留来源、性质、反证与不确定性。
- 把高价值想法编译为可执行任务图与跨媒介作品，并将过程、失败、成品和复盘写入长期账本。
- 以 `docs/MUSE_CONSTITUTION.md` 为治理原则，以 `docs/PROJECT_PROMETHEUS.md` 为使命路线；两者均可通过有记录的实践反馈修订。

## 当前实现范围
src/muse/philosophy.py 提供持久化经验、六项初始原则、经验关联、实验登记、结果回写与 CLI 概览。当前提炼使用可解释关键词规则，不声称具备自主意识；后续接入研究报告、失败事件、用户反馈和改进提案，并用评估集校准质量。
