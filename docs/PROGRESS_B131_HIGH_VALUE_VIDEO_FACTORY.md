# B131 · 高价值视频工厂与宇宙级产品概念扩展

日期：2026-11-13
状态：路线图与现状审计已写入；生产/发布/收益闭环尚未完成。

## 用户目标

继续完善 Muse 的「宇宙最强 APP / 宇宙意识中枢」概念，并打通高价值视频产出链，希望自动生成可在不同平台发布并有机会获得收益的视频。

## 本轮实际审计发现

- 本地 Wan 2.1 T2V 1.3B 工作流已经存在：`src/muse/wan_video.py`。使用固定 allowlist 节点与 loopback ComfyUI，当前接口约束为 512 级预览、12 FPS、1-5 秒单镜头。
- `src/muse/video_product_builder.py` 已支持本地 Wan 单镜头文生视频和本地素材合成，并生成 MP4、storyboard、manifest、ZIP、SHA-256 校验；产品关联 Creator Initiative / Research Wiki。
- `scripts/muse-high-value-short.py` 已有研究驱动短视频范例：六段本地 Wan 镜头、FFmpeg 竖屏合成、中文字幕、原创合成氛围音、封面、来源笔记、产品包、知识节点和演化周期关联。
- `scripts/muse-prometheus-film.py` 已有多镜头产品片生产脚本，支持复用已验证镜头、按需生成、Dashboard 实际截图、横/竖版封装。
- 桌面 UI 已显示视频任务/引擎/产品，支持下载 MP4 与 ZIP、校验和人工反馈。
- 产品状态仍以 testing 为主，正式发布前要求人工验收。

## 重要缺口

- 没有找到完整官方平台发布/OAuth适配、发布队列、发布状态回读。
- 没有完整平台分析和收益到账数据回流。
- 选题评分、受众需求、脚本与分镜通用化、统一技术/内容质量门禁尚不完整。
- 本地中文 TTS 尚未验证；已有高价值短片明确没有旁白。
- 不能保证播放、粉丝、广告分成或收入；也不能把估算数据写成真实收入。
- 各平台 API 权限和商业化资格依账号/地区/政策变化，需逐个平台验证。

## 本轮新增本地产品规范

- 新建 `docs/MUSE_HIGH_VALUE_VIDEO_FACTORY.md`，记录端到端视频工厂流程、选题评分、研究证据规范、版权追溯、多画幅制作、技术/内容门禁、官方账号授权发布、平台分析与收益回流、A/B 实验和验收定义。
- 明确自动化优先覆盖研究、创作、渲染、质检、元数据与发布准备；平台账号必须官方授权，不能绕过风控；发布/收益只按真实平台响应和报表记账。
- 将“有价值、原创、可验证、可持续”定为内容策略，不鼓励低质批量搬运。

## 下一阶段实施顺序

1. 把现有 `muse-high-value-short.py` 提炼为可配置生产配方，并统一平台发布包元数据与来源/版权清单。
2. 建立统一 Video QA Gate：FFprobe、完整解码、音频响度/静音、黑帧/静帧、字幕时序、封面与 ZIP 校验。
3. 增加多平台发布包导出和每个平台独立的 profile；先做到可靠手动发布包，再逐平台接官方 API/OAuth。
4. 账号授权后逐平台接入官方发布 API、幂等发布队列与状态回读。
5. 读取官方分析/收益数据，区分播放指标、预估收益、已结算收入。
6. 把真实表现回流到研究/知识/演化闭环。

## 验证边界

本轮只完成代码审计与产品规范文档，不声称平台发布、自动变现或全自动生产闭环已经完成。需要实机生成与平台账号授权的步骤必须单独验收。
