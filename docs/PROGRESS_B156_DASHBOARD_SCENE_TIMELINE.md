# B156｜Dashboard 分镜运镜与场景时间轴

日期：2026-11-18

## 本轮目标

承接 B154 的真实 Remotion 动态成片 E2E，将 storyboard 中的逐镜头运动指令、镜头时间范围和转场时长安全地送到本地 Dashboard 产品库，令每个视频产品可以直接查看并定位预览对应镜头。

## 实现

修改文件：

- `src/muse/status_api.py`
- `ui-prototype/src/lib/api.ts`
- `ui-prototype/src/App.svelte`
- `tests/test_status_api.py`

### 1. 产品 API 安全摘要

- 从已经通过产品完整性验证的 `storyboard.json` 读取场景列表。
- 最多输出 100 个场景；仅允许受限字符集的 scene ID、素材文件名和已知 camera move。
- 只输出有限、非负的数值时间字段；若结束时间早于开始时间，丢弃该场景时间定位。
- 不返回任意 storyboard 元数据、绝对路径、原始 prompt 或私有字段。
- 非法 JSON、非法路径形态、未知运镜不会导致产品列表接口崩溃或向前端泄露原始内容。

### 2. Dashboard 产品库

- 产品卡展示镜头编号、素材名、中文运镜标签。
- 若存在有效时间轴，展示开始/结束时间、时长与入场/出场转场时长。
- 提供“预览此镜头”操作，使用现有产品预览能力从镜头开始时间定位。
- 没有时间轴的旧产品继续兼容，只显示可验证的场景字段；没有 storyboard 场景时不显示空面板。

### 3. 回归测试

扩展产品列表测试，覆盖：

- 有效镜头数据与转场时间正确输出。
- 含目录穿越的素材名被拒绝。
- 未知 camera move 不被输出。
- 现有 QA 警告映射、音频 LUFS 指标与隐私字段过滤仍然有效。
